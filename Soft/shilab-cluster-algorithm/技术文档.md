## 1. 项目背景与核心目标

### 1.1 背景

在肺癌病理诊断中，病理切片（候选域）包含大量细胞，需要从中准确识别恶性细胞亚群。
传统方法依赖人工标注，耗时耗力且主观性强。本包通过**跨域簇匹配**方法，
利用已知标注的参考细胞（参考域）指导对未标注病理切片的分析。

### 1.2 核心目标

- **参考域**：已知类型的恶性细胞（LUAD / LUSC / SCLC / Malignant）和良性细胞（Benign）
- **候选域**：待分析的病理切片细胞（来自阳性 / 阴性病例）
- **任务**：通过深度特征提取 + 聚类 + 跨域相似度匹配，自动识别候选域中与参考恶性簇高度相似的细胞亚群

### 1.3 支持的细胞类型标签

| source_label | 类别名称  | 说明             |
|:---:|:---:|:---|
| 0            | Candidate | 候选域细胞（待分析）     |
| 1            | LUAD      | 肺腺癌细胞           |
| 2            | LUSC      | 肺鳞癌细胞           |
| 3            | SCLC      | 小细胞肺癌细胞         |
| 4            | Benign    | 良性细胞             |
| 5            | Malignant | 通用恶性细胞          |

### 3.1 `models/models.py` — 模型定义层

#### 职责

定义所有支持的 CNN 骨干网络特征提取器，并提供统一的工厂函数接口。

#### 工厂函数

```python
get_model_and_transform(model_type, model_path, num_classes=2, mean=None, std=None)
```

| 参数         | 类型   | 说明                                      |
|:---|:---:|:---|
| model_type   | str    | 模型类型字符串，见下表                    |
| model_path   | str    | 预训练权重文件路径（.pth）                |
| num_classes  | int    | 分类头输出类别数，默认为 2                |
| mean / std   | list   | 图像归一化参数，None 时使用 ImageNet 默认值 |

**返回值**：`(model, transform)` — 模型实例 + 对应的图像预处理变换

#### 支持的模型列表

| model_type 参数    | 对应类                                  | 输出特征维度 | 特征提取方式                         |
|:---|:---|:---:|:---|
| `'AlexNet'`        | CustomAlexNetFeatureExtractor           | 4096         | classifier 前 6 层（含 2 个 Linear+ReLU） |
| `'ResNeXt'`        | CustomResNeXtFeatureExtractor           | 2048         | 去除 FC 层，保留 GAP 输出             |
| `'ResNet50'`       | CustomResNet50FeatureExtractor          | 2048         | 去除 FC 层，保留 GAP 输出             |
| `'ResNet101'`      | CustomResNet101FeatureExtractor         | 2048         | 去除 FC 层，保留 GAP 输出             |
| `'ConvNeXt'`       | CustomConvNextLargeFeatureExtractor     | 1536         | classifier[-1] 替换为 Identity        |
| `'GoogLeNet'`      | CustomGoogLeNetFeatureExtractor         | 1024         | FC 替换为 Identity                    |
| `'DenseNet121'`    | CustomDenseNet121FeatureExtractor       | 1024         | classifier 替换为 Identity            |
| `'DenseNet161'`    | CustomDenseNet161FeatureExtractor       | 2208         | classifier 替换为 Identity            |
| `'VGG16'`          | CustomVGG16FeatureExtractor             | 4096         | classifier 前 6 层                    |
| `'InceptionV3'`    | CustomInceptionV3FeatureExtractor       | 2048         | FC 替换为 Identity                    |
| `'EfficientNetB0'` | CustomEfficientNetB0FeatureExtractor    | 1280         | classifier 替换为 Identity            |
| `'EfficientNetV2L'`| CustomEfficientNetV2LFeatureExtractor   | 1280         | classifier 替换为 Identity            |

#### 统一设计模式

所有模型类遵循相同的设计模式：

```
Step 1  加载标准 torchvision 模型（pretrained=False）
Step 2  修改分类头以匹配训练时的结构（num_classes）
Step 3  调用 load_weights() 加载自定义训练权重
         └── 自动处理键名前缀不匹配（如 'resnext.' / 'alexnet.' 前缀）
Step 4  将分类头替换为 nn.Identity() 或截断
         └── 使 forward() 输出倒数第二层特征向量
Step 5  forward(x, layer='penultimate') 统一接口
         ├── layer='penultimate' → 返回特征向量（默认）
         └── layer='final'       → 返回分类 logits（部分模型支持）
```

#### 权重加载容错机制

训练时保存的权重文件可能包含自定义前缀（如 `resnext.`、`alexnet.`），
`load_weights()` 会自动检测并去除这些前缀，确保权重正确加载：

```python
# 以 ResNeXt 为例
for k, v in state_dict.items():
    if k.startswith('resnext.'):
        new_state_dict[k[8:]] = v   # 去除 'resnext.' 前缀
    else:
        new_state_dict[k] = v
self.resnext.load_state_dict(new_state_dict, strict=False)
```

### 3.2 `models/feature_extractor.py` — 特征提取层

#### 职责

将模型推理与细胞大小信息融合，生成最终用于聚类的特征向量。

#### 核心函数

```python
extract_features_with_cell_size(
    model, dataloader, device, cell_sizes,
    feature_layer='penultimate',
    cell_size_weight=1.0
)
```

| 参数               | 说明                                          |
|:---|:---|
| model              | 已加载权重的特征提取器实例                    |
| dataloader         | PyTorch DataLoader，批量输入图像              |
| device             | 推理设备（CPU / CUDA）                        |
| cell_sizes         | 每张图像的细胞大小数组（非背景像素数，已 log 变换） |
| feature_layer      | 提取层级，默认 'penultimate'                  |
| cell_size_weight   | 细胞大小特征的拼接权重，默认 1.0              |

#### 特征融合逻辑

```
输入图像 batch [N, C, H, W]
    ↓ model.forward(layer='penultimate')
深度语义特征向量 [N, D]       （D = 模型输出维度，如 2048）
    ↓ np.concatenate
细胞大小特征    [N, 1]  × cell_size_weight
    ↓
融合特征向量    [N, D+1]      （送入后续 PCA 降维和聚类）
```

**设计意图**：恶性细胞通常在形态上与良性细胞有显著差异（体积更大、核质比更高），
将细胞大小作为显式特征维度，增强聚类的区分能力，弥补纯语义特征的不足。

### 3.4 `clustering/K_optimizer.py` — K 值优化层

#### 职责

为每个候选域病人切片自动确定最优聚类数 K，避免固定 K 值带来的欠聚类或过聚类问题。

#### 核心函数

```python
optimize_k_for_candidate_clustering(
    candidate_features_norm,
    reference_results,
    k_range,
    malignant_ref_indices,
    patient_id,
    save_dir
)
```

#### 优化策略

```
遍历 k ∈ [k_min, min(k_max, N//3)]，步长 = 2
    ↓
对每个 k 执行 KMeans 聚类
    ↓
计算综合评分（加权求和）：
    ├── 簇内紧密度 (Intra-cluster Cohesion)
    │     └── 簇内样本与簇中心的平均余弦相似度
    ├── 恶性匹配得分 (Malignant Match Score)
    │     └── 候选簇中心与 R0/R5 的最大余弦相似度
    └── 簇间分离度 (Inter-cluster Separation)
          └── 各簇中心间的平均距离
    ↓
选择综合评分最高的 k 值
    ↓
绘制 K 优化曲线（plot_k_optimization_curve）并保存
```

#### 辅助函数

**`plot_k_optimization_curve(k_values, scores, best_k, patient_id, save_dir)`**

绘制 K 值 vs 综合得分曲线，用红色虚线标注最优 K 值，便于人工复核。

### 3.5 `clustering/matching_rule_application.py` — 匹配规则层

#### 职责

定义跨域簇匹配的规则逻辑，并将规则应用于候选域聚类结果，筛选出恶性候选簇。

#### 核心函数

**① `check_matching_rules(similarities, ref_idx_target, ref_idx_avoid, threshold_target, threshold_avoid_others)`**

通用规则检查函数，判断一个候选簇是否满足匹配条件：

```
规则结构：
    条件1: sim(候选簇, 目标参考簇) >= threshold_target      （相似度下限）
    条件2: sim(候选簇, 其他所有参考簇) < sim(目标) / 3      （排他性约束）
    → 两个条件同时满足 → 该候选簇匹配成功
```

| 参数                    | 说明                               |
|:---|:---|
| similarities            | 候选簇与所有参考簇的相似度向量      |
| ref_idx_target          | 目标参考簇索引（R0 或 R5）          |
| ref_idx_avoid           | 排除比较的参考簇索引                |
| threshold_target        | 目标相似度阈值，默认 0.5            |
| threshold_avoid_others  | 其他簇的绝对相似度上限（可选）      |

**② `identify_matching_clusters(reference_results, candidate_results, similarity_matrix)`**

将两条规则批量应用于所有候选簇，返回匹配到的簇索引列表：

```
规则 1（R5 主导型恶性匹配）：
    候选簇与 R5（index=5）的相似度 >= 0.5
    且 与其他所有参考簇的相似度 < sim(R5) / 3
    （比较时忽略 R0）

规则 2（R0 主导型恶性匹配）：
    候选簇与 R0（index=0）的相似度 >= 0.5
    且 与其他所有参考簇的相似度 < sim(R0) / 3
    （比较时忽略 R5）
```

**③ `save_matched_cells(matched_cluster_indices, candidate_results, save_dir)`**

将匹配到的恶性候选簇中的所有细胞图像复制到指定输出目录，
按簇分子目录保存，便于后续人工复核。

### 3.6 `clustering/calculate_consensus_score.py` — 共识得分层

#### 职责

对已匹配的候选簇计算双向共识得分，量化匹配置信度，为最终结果提供可信度评估。

#### 核心函数

```python
calculate_consensus_score(
    reference_results,
    candidate_results,
    matching_pairs,
    save_dir=None
)
```

#### 双向共识计算逻辑

```
方向 A：候选 → 参考（Candidate-to-Reference）
    对匹配候选簇中的每个细胞：
        计算该细胞与 R0 簇中心的相似度 sim_R0
        计算该细胞与 R5 簇中心的相似度 sim_R5
        若 max(sim_R0, sim_R5) > sim(其他参考簇)
        → 该细胞"支持"匹配
    candidate_consensus = 支持细胞数 / 总细胞数

方向 B：参考 → 候选（Reference-to-Candidate）
    对 R0/R5 中的每个细胞：
        计算该细胞与所有候选簇中心的相似度
        若最近邻落在目标候选簇
        → 该参考细胞"支持"匹配
    reference_consensus = 支持参考细胞数 / 总参考细胞数

最终共识得分 = (candidate_consensus + reference_consensus) / 2
```

**设计意图**：单向匹配容易产生假阳性（候选簇碰巧与恶性参考簇相似），
双向验证要求两个方向都高度一致，显著降低误匹配率。

### 3.8 `application/qrr_pipeline.py` — 主流水线层

#### 职责

这是整个包的**唯一对外入口**，`run_pipeline()` 函数串联所有子模块，
完成从原始图像输入到最终匹配结果输出的完整流程。

#### 函数签名

```python
run_pipeline(
    positive_folder,          # 阳性候选域图像根目录
    negative_folder,          # 阴性候选域图像根目录
    malignant_cells_dir,      # 参考域恶性细胞目录
    benign_cells_dir,         # 参考域良性细胞目录
    model_type,               # 模型类型字符串（如 'ResNeXt'）
    model_path,               # 模型权重文件路径
    save_dir,                 # 结果保存根目录
    reference_k=10,           # 参考域聚类数（固定）
    k_min=2,                  # 候选域 K 值搜索下限
    k_max=20,                 # 候选域 K 值搜索上限
    pca_components=32,        # PCA 降维维度
    batch_size=32,            # DataLoader batch size
    num_workers=4,            # DataLoader 工作进程数
    cell_size_weight=1.0,     # 细胞大小特征权重
    threshold_target=0.5,     # 匹配相似度阈值
    malignant_ref_indices=[0,5]  # 恶性参考簇索引
)
```

#### 流水线执行阶段

```
阶段 0：初始化
    设备检测（CPU / CUDA）
    随机种子固定（seed=42，保证可复现）
    加载模型与图像预处理变换

阶段 1：参考域处理（执行一次）
    collect_reference_data()          → 收集恶性 + 良性参考细胞路径与标签
    count_non_background_pixels()     → 计算每张图像的细胞大小
    log 变换 + 归一化细胞大小
    CellImageDataset + DataLoader     → 构建数据集
    extract_features_with_cell_size() → 提取深度特征 + 拼接细胞大小
    PCA(n_components=32)              → 降维（fit_transform，保存 pca 对象）
    L2 normalize                      → 归一化到单位球面
    KMeans(k=reference_k)             → 聚类（固定 k=10）
    保存参考域聚类结果 reference_results
    可视化：UMAP 全局图 + 缩略图 + 簇组成柱状图

阶段 2：候选域循环处理（每个病人切片执行一次）
    collect_image_paths()             → 收集候选细胞路径
    count_non_background_pixels()     → 计算细胞大小
    CellImageDataset + DataLoader     → 构建数据集
    extract_features_with_cell_size() → 提取深度特征
    pca.transform()                   → 复用参考域 PCA（特征空间对齐！）
    L2 normalize                      → 归一化
    optimize_k_for_candidate()        → 自动搜索最优 K 值
    KMeans(k=best_k)                  → 以最优 K 聚类
    cosine_similarity()               → 计算候选簇中心与参考簇中心的相似度矩阵
    identify_matching_clusters()      → 应用双规则匹配
    calculate_consensus_score()       → 计算双向共识得分
    save_matched_cells()              → 保存匹配细胞图像
    可视化：相似度热力图 + 匹配结果图 + 筛选结果图
    写入 results_stats（汇总统计）

阶段 3：汇总输出
    将所有病人的匹配结果写入汇总 CSV 文件
```

**关键设计**：参考域的 PCA 模型在候选域处理时**复用**（`pca.transform` 而非 `fit_transform`），
确保参考域与候选域的特征向量处于**同一特征空间**，使跨域相似度计算有意义。

## 5. 关键算法说明

---

### 5.1 特征融合策略

**问题**：纯深度语义特征可能忽略细胞形态差异（大小、面积）。

**方案**：将细胞大小（非背景像素数）经 log 变换后，作为额外维度拼接到深度特征向量末尾。

```
cell_size = count_non_background_pixels(image)   # 统计非(225,225,225)像素数
cell_size_log = log(cell_size + 1)               # log 变换，压缩量纲
final_feature = concat([deep_feature, cell_size_log * weight])
```

**背景像素定义**：RGB 值恰好为 (225, 225, 225) 的像素视为背景（细胞图像的填充色）。

---

### 5.2 K 值自动优化算法

**问题**：不同病人切片的细胞数量和多样性差异大，固定 K 值不适用。

**综合评分公式**：

```
Score(k) = w1 × Cohesion(k) + w2 × MalignantMatch(k) + w3 × Separation(k)

其中：
  Cohesion(k)       = mean(簇内样本与簇中心的余弦相似度)
  MalignantMatch(k) = max(sim(候选簇中心, R0), sim(候选簇中心, R5)) 的均值
  Separation(k)     = mean(各簇中心间的余弦距离)
```

搜索范围：`k ∈ [k_min, min(k_max, N//3)]`，步长为 2（只搜索偶数 K，减少计算量）。

---

### 5.3 双规则匹配机制

**问题**：单一相似度阈值容易产生假阳性（良性簇碰巧与恶性参考簇相似）。

**解决方案**：引入排他性约束，要求候选簇"专一"地与目标恶性参考簇相似：

```
规则 1（R5 主导）：
    sim(候选簇, R5) >= 0.5
    AND
    ∀ i ≠ R5, i ≠ R0: sim(候选簇, Ri) < sim(候选簇, R5) / 3

规则 2（R0 主导）：
    sim(候选簇, R0) >= 0.5
    AND
    ∀ i ≠ R0, i ≠ R5: sim(候选簇, Ri) < sim(候选簇, R0) / 3
```

**排他性比值 1/3** 的含义：候选簇与目标恶性簇的相似度，必须是其与任何良性参考簇相似度的 3 倍以上。

---

### 5.4 双向共识得分计算

**问题**：匹配规则基于簇中心，可能掩盖簇内部的异质性。

**方案**：在细胞级别进行双向验证：

```
方向 A（候选 → 参考）：
    对匹配候选簇中每个细胞 c_i：
        若 max(sim(c_i, R0_center), sim(c_i, R5_center)) > sim(c_i, 任意良性参考簇中心)
        → 该细胞"支持"匹配
    Score_A = 支持细胞数 / 总细胞数

方向 B（参考 → 候选）：
    对 R0 + R5 中每个参考细胞 r_j：
        若 argmax(sim(r_j, 所有候选簇中心)) == 目标候选簇
        → 该参考细胞"支持"匹配
    Score_B = 支持参考细胞数 / 总参考细胞数

Final Consensus Score = (Score_A + Score_B) / 2   ∈ [0, 1]
```

## 7. 核心设计决策

| 设计点               | 具体实现                                    | 原因                                           |
|:---|:---|:---|
| **特征空间对齐**     | 候选域复用参考域 PCA（`transform` 非 `fit`）  | 确保两域特征向量在同一空间，使余弦相似度有意义  |
| **形态特征融合**     | 细胞大小拼接到特征向量末尾                   | 恶性细胞形态差异显著，弥补纯语义特征的不足      |
| **固定参考域 K=10**  | 参考域 KMeans 固定 k=10                      | 参考域数据固定，手动调优后固定，保证簇索引稳定  |
| **动态候选域 K**     | 步长 2 遍历，综合评分选最优                  | 不同病人细胞数量差异大，动态适应                |
| **硬编码恶性簇索引** | R0=index 0, R5=index 5                       | 需与参考域聚类结果对应，使用前需验证            |
| **双规则匹配**       | R5 主导 + R0 主导，排他性比值 1/3            | 减少假阳性，确保候选簇"专一"匹配恶性参考簇      |
| **双向共识验证**     | 候选→参考 + 参考→候选，取均值                | 细胞级别验证，降低簇中心匹配的假阳性            |
| **随机种子固定**     | seed=42，torch/numpy/cudnn 全部固定          | 保证实验结果可复现                              |
| **多模型支持**       | 工厂函数 + 统一 forward 接口                 | 方便切换骨干网络，对比不同模型的效果            |
